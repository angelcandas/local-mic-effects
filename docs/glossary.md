# MicFX glossary

One word, one thing. Use these names in UI text, tooltips, the "?" overlays and the user manual.
When a new feature needs a name, check this list first and add the word here in the same PR.

| Word | Means | Not to be used for |
|---|---|---|
| **Live mode** | The screen you sing through on stage or in practice | |
| **DAW mode** | The multitrack screen: tracks, clips, mixer | |
| **Looper** | The Live-mode looper (top bar button "Looper", keys L and K) | the DAW loop range |
| **Loop range** | The DAW's marked range that playback repeats (ruler, key L, toolbar loop button) | the looper |
| **Loop this clip** | Sets the loop range to the selected clip (Ctrl+L) | |
| **Patterns** | The pattern looper's tab and its patterns | |
| **Repeat phrase** | Practice: play one phrase again and again | |
| **Mic check** | Sets the input gain from a few seconds of singing | |
| **Sound check** | Sets the whole Live chain for the voice, mic and room | |
| **Mix Check** | The DAW report on the mix with Fix buttons (toolbar button "Mix Check") | |
| **Mon** | A track's monitor button; its states are Mon (always), Auto (while armed) and Off | the chain's In gain |
| **In gain / Out gain** | The level into and out of an effect or a chain | monitoring |
| **Input** | The audio input a track records from (mixer input picker) | |
| **Mute** | A DAW track mute (M or 0) | Live's panic button |
| **Mute output** | Live mode's panic button (M) | |
| **Preset** | One effect's saved settings. A whole chain becomes a **Sound** with the Ableton-style effects rework | |
| **Scene** | A snapshot of the Live sound for a song part. The clip launcher's rows must use another word ("Rows") | |
| **Setlist** | The songs of a show, each with its sound, scenes and backing track | |
| **Clip tab** | The bottom-panel tab that shows the selected clip, pitch and time and the piano roll | "Track tab" |
| **Tempo** | The tempo track toggle on the DAW toolbar | |
| **Take** | One pass of a recording in a DAW take lane | Live sing-along rows |
| **Recording** | A row of Live mode's sing-along list | |
| **Capture** | Keeps what you just played even if you were not recording (toolbar button "Capture") | "Cap" |
| **Voice up front** | The Auto Mix and Mix Check style for a dry, upfront voice (stored as `coaching`) | "Coaching" |
