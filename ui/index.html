How it works

Tag what's on each track (voice, background vocals, drums, bass...), then Auto Mix listens and adds the effects each one needs (EQ, compressor, de-esser, reverb and more), sets the levels and writes volume rides. Nothing plays while it listens: it measures every track offline, many times faster than real time, and listening again only measures the tracks you changed. One undo takes it all back.
